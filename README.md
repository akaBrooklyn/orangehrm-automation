# OrangeHRM Automation Framework

## 🔧 Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven

## 📌 Modules Automated
- Login
- PIM (Add Employee)
- Admin (Add User)
- Leave (Navigation)
- Recruitment
- Performance
- Reports

## 🚀 How to Run
1. Clone the repo
2. Import as Maven Project in Eclipse
3. Run testng.xml
